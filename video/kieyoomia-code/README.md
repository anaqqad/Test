# The Navajo code and Joe Kieyoomia (WWII Frontlines)

The Navajo code talkers (Johnston's idea, the first 29, the code, Guadalcanal to Iwo Jima) told through Joe Kieyoomia, a
Navajo soldier of New Mexico's 200th Coast Artillery captured on Bataan, whom the Japanese tortured to break the code he
had never learned. Topic and title format from reference channel Sealed Orders ("The True Story of..."), 28:42 long.
Script in `script.md`, sources in `research/sources.md` (Kieyoomia's details attributed; Nagasaki told as three versions).

New in this episode: `remotion/src/cards.tsx` (CastCard, Headline, CodeWord) and `remotion/src/devices.tsx` (QuoteCard,
DocDesk, GlobeMap from the quote-card-reveal, doc-desk-3d and war-room-globe-maps skills). Built at 1080p:
`HEIGHT=1080 bash tools/render_missing.sh`, `python tools/assemble.py --clips-only --hd`, `python tools/assemble_parts.py 8`.
