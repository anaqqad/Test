# Media candidates: "Navy File Shows What George H.W. Bush Really Did in WW2"

Compiled 22 Nov 2026. Every URL below was queried through the archive.org metadata API, the NARA catalog API
(catalog.archives.gov/proxy), the Wikimedia Commons API or an HTTP HEAD check. Nothing was downloaded except
a few page scans used to confirm that documents are readable.

Licence key: **PD-USGov** = work of a U.S. federal employee on official duty (Navy, Army Signal Corps / AAF,
White House Television, NARA). archive.org "PD Mark" items are NARA films re-uploaded with the Public Domain Mark.
For archive.org, the best file is always the `.mov` (1280x720 ProRes/H.264 upscale of the NARA transfer) or
the original NARA `.mp4`, and **never** `_512kb.mp4`.

**Watch-outs**
- Bush Library "H-series" photos are family-album prints that NARA catalogs as *Use: Unrestricted*. The cockpit,
  squadron and rescue images are Navy photos. Personal snapshots (wedding, family) are less certain, so credit
  "George Bush Presidential Library and Museum" on screen.
- Periscope Film uploads (identifiers ending `vwr`, `XD####`) show Navy footage but carry a corner watermark. Use them
  only if no NARA copy exists.
- *The Fighting Lady* (1944, full film at archive.org/details/FightingLady, 640x480 MPEG2) was distributed by 20th
  Century-Fox. archive.org marks it PD, but the Fox copyright/renewal status is unclear. **Use the Navy outtake reels
  NPC-2658/NPC-2661 instead**: they are certainly PD and include the same Marcus-raid TBM shots.
- The Tachibana trial file describes torture, executions and cannibalism (Maj. Matoba). Keep the narration factual
  for the 65+ audience and show text, not gore.
