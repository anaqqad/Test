# Malta v5: board sources (one line per string on the board)

Rule from the owner (2026-11-21): a string goes on the board only if it finishes the sentence
"This source supports this specific claim because…". Strings run from evidence to the finding it supports.
Labels: RECORDS / SHOWS (solid red), SUGGESTS (dashed red, an inference), CHALLENGES / SUPPORTS (blue, a test),
NOT SHOWN (grey dashed, a step left open on purpose).
