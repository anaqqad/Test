## Investigation board: what each string means
A string runs only from a piece of evidence to the conclusion it supports:
- Abbate report (c. 1241) → "Malta's Christians already spoke the dialect" (Christians present and counted; the dialect continuity is Wettinger's reading)
- 1400s surnames (42.5 % Arabic origin) → same conclusion
- Lucera deportations → "Sicily: its Arabic speakers removed, settlers arrived"
- both conclusions → "The religion changed. The language stayed."
Claims that the evidence revises are rewritten on their cards: al-Himyari (CLAIM → DISPUTED), "never written down" (→ REVISED: rarely written, a poem before 1485), Phoenician origin (→ LINGUISTS' VERDICT).
