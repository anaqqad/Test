# Sound effect sources
- `discord_pop.wav`: Discord's message notification sound, from myinstants.com ("discord-notification.mp3"), trimmed. Third-party audio, used at the owner's request (2026-11-17), the same sound the Beluga reference uses. Fallback: our own `pop.wav`.
- All other files: synthesised for LingoDude by `chat/make_sfx.py` (sine tones and noise).
