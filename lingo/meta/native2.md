Native American Languages be like… (Part 2)

## Description
Seven more Native languages of North America, each one real and each one rare: Tlingit has no p, b or m sounds, Karuk has no known relatives, Kumeyaay is spoken on both sides of the US–Mexico border, and Comanche was the code the enemy couldn't break in World War II. Every voice you hear is a real recording of the language.

Part 1 (Navajo, Cherokee, Ojibwe, Lakota, Crow, Gwich'in) is on the channel. Which Native language should we add next? Tell us in the comments 👇
