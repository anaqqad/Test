# YouTube metadata: Ranking Languages by How Fast They're Spoken

## Title
Ranking Languages by How Fast They're Spoken

## Description
Which language is spoken the fastest? We didn't take anyone's word for it: we timed real native speakers reading a paragraph aloud and counted every single syllable. Watch the counter, the stopwatch and the speedometer run live.

How we measured: one read paragraph per language (17 to 25 seconds), one speaker each. Syllables are counted from the exact words spoken, numbers counted as said aloud. The stopwatch only runs while the person is speaking, so pauses and breaths don't count. Speed = syllables ÷ speaking time. Different speakers talk at different speeds, so this is one real person per language, not an average of the whole language.

Results: German 6.80, Japanese 6.35, Italian 5.88, Spanish 5.35, English 4.94, French 4.78, Vietnamese 4.71, Mandarin 4.38 syllables per second.

Which language should we time next? Tell us in the comments 👇
